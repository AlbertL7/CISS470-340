The sentence to remember

Publish a website that retrieves fictional data through a server-side API. The browser never connects directly to MySQL and never receives a database password.

What you are building

  • A seven-table MySQL 8.4 LTS database named shopflow
  • A complete Colab notebook with cleaning, validation, ten queries, and five interactive visualizations
  • A public, read-only GitHub and Netlify demonstration site showing selected views
  • A short professional report explaining your decisions and AI verification

What this is—and is not

This is a guided learning prototype, not a production shopping system. All ShopFlow records are fictional and intentionally messy. Do not add real customer information.

The notebook contains the full analytics work. The website demonstrates selected database results; it does not have to reproduce every notebook query or chart.

Setup account

avnadmin

Use the Aiven administrator only in Colab or the MySQL command line to create the schema, load data, and create the limited website user. Never place this account in GitHub or Netlify.

Website account

shopflow_reader

Use this SELECT-only account in the Netlify Function. Store its password as a Netlify environment variable, not in source code.

Credential and AI safety

Never paste passwords, tokens, complete connection strings, private keys, or unredacted records into an AI tool, notebook output, screenshot, GitHub repository, or report. Use Colab Secrets and Netlify environment variables. If a secret is exposed, rotate it immediately.

AI may produce drafts, but students must test, correct, document, and explain every submitted result.

Metric contract: calculate the same idea the same way

Use these definitions in the notebook, report, API, and website
MetricCanonical definitionValidation question
Line revenueUse order_items.line_total; verify it matches quantity × unit price after any applicable discount.Does each order-item row appear exactly once before summing?
Project revenueSum line_total at the order-item grain. Document and consistently reuse any instructor-approved order-status filter.Did a later join to reviews or tickets multiply order items?
Customer lifetime valueProject revenue grouped by one unique customer_id, then summarized by segment.Are customers counted once in the segment summary?
Conversion rateRecovered abandoned carts divided by eligible abandoned carts, multiplied by 100.Are the numerator and denominator from the same eligible population?
Repeat customerA customer with at least two qualifying completed orders.Are distinct orders counted rather than line items?

Use a control total

Before making charts, calculate one trusted total from the smallest correct table set. Compare every later revenue query to that control. If the total changes after joining reviews, support tickets, or other one-to-many tables, investigate the query grain.

Recommended read-only account pattern

Use a unique password stored outside the notebook and repository. Your final code must retrieve it from a secret or environment variable.

CREATE USER 'shopflow_reader'@'%'
  IDENTIFIED BY 'use-a-secret-not-this-placeholder';
GRANT SELECT ON shopflow.* TO 'shopflow_reader'@'%';
SHOW GRANTS FOR 'shopflow_reader'@'%';
What “same-origin function” means

The page and function are deployed together. Browser JavaScript requests a relative path instead of a hard-coded deployment hostname:

const API_BASE_URL = '/.netlify/functions';
const response = await fetch(`${API_BASE_URL}/products`);

The function—not the browser—uses the reader credentials to query Aiven and return JSON.

Three AI evidence cards

Choose three moments that changed your understanding or fixed a meaningful problem. Each card should answer:

  1. Prompt: What did you ask, without including secrets or private data?
  2. Prediction: What did you expect the suggestion to do?
  3. Test: What query, control total, error message, or comparison did you use?
  4. Correction: What was wrong or incomplete, and how did you revise it?
  5. Lesson: What can you now explain without AI?

500-word reflection

Explain the data flow, schema decisions, cleaning work, and selected queries. Discuss how your three AI examples affected your reasoning, where AI was unreliable, how you verified its work, and what you would do differently next time.
